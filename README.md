# AutoWorks

AutoWorks is a modern web application for an auto repair service.
The project includes a responsive client-facing website with company information and a booking system integrated with a CMS dashboard.

---

## 🚀 Tech Stack

* React
* TanStack Query
* Strapi CMS
* React Router
* CSS / Responsive Design

---

## ✨ Features

* Auto repair booking system
* CMS dashboard integration
* Responsive design for mobile and desktop
* Company information pages
* Dynamic API data fetching
* Client-side routing

---

## 🛠️ Installation

```bash
npm install
npm run dev
```
